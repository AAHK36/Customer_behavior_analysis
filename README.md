# Customer_behavior_analysis
This project analyzes 3,900 retail transactions ($233K revenue) to understand what drives spending and how subscriptions and discounts affect revenue. Data was cleaned and feature-engineered in Python (pandas), stored in PostgreSQL, queried to answer nine business questions in SQL, and presented in an interactive Power BI dashboard. Key findings: subscribers don’t spend more than non-subscribers, about half of purchases of five items (Hat, Sneakers, Coat, Sweater, Pants) use discounts, and 80% of customers are in the Loyal segment with only 2% new. The report closes with recommendations on subscription benefits, discount policy, loyalty programs and customer acquisition.
